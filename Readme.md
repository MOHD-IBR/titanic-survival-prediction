# Titanic Survival Prediction

This is a basic data science project I made for my Data Science course.

I used the Titanic dataset to predict which passengers were more likely to survive the accident.

### What I did in this project:
- Loaded the Titanic data
- Cleaned the missing values
- Did some basic analysis and made graphs
- Converted text data into numbers
- Built a Logistic Regression model
- Checked the accuracy of the model

### Libraries used:
- pandas
- seaborn
- matplotlib
- scikit-learn

### How to run
Just open the notebook (or python file) and run all the cells.  
The dataset is already available in seaborn so no need to download anything.

### Results
The model gave decent accuracy. From the analysis it was clear that women and first class passengers had higher survival rate.

This was a good project to practice data cleaning, EDA and basic machine learning.
